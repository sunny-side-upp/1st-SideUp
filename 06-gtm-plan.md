# 06 — GTM Plan

## GTM motion

**Product-led discovery + sales-assisted conversion**

The first objective is not mass acquisition. It is finding a repeatable use case with a measurable activation event.

## Phase 1 — Design partners

Target 5–10 e-commerce brands.

Offer:
- Catalog workflow audit
- 50–100 SKU pilot
- Baseline production-time measurement
- Before/after asset comparison
- Weekly feedback session

Capture:
- Time per asset
- Revision rate
- Approval rate
- Assets produced per creative-hour
- User satisfaction
- Reasons for rejection

## Phase 2 — Demand creation

### SEO

Create pages around high-intent problems:
- AI product photography for ecommerce
- product image automation
- bulk product photo editing
- ecommerce image workflow
- product image consistency
- AI catalog image generation

### Content

**Pillar:** The E-commerce Visual Production Playbook

Clusters:
1. Product image standards
2. Marketplace image requirements
3. Catalog consistency
4. AI product photography
5. Creative operations
6. Visual experimentation

### Outbound

Trigger-based outreach:
- Hiring surge in creative/e-commerce
- Large SKU expansion
- New market launch
- New marketplace launch
- Frequent seasonal campaigns

## Phase 3 — Expansion

**More SKUs → more channels → more teams → API / workflow integration**

## Funnel

Traffic → Interactive demo → Upload first product → Generate asset set → Approve first asset → Activate 10+ SKUs → Invite teammate → Pilot → Paid account → Expansion

## PMM role across funnel

| Funnel stage | PMM contribution |
|---|---|
| Awareness | Category narrative + SEO |
| Consideration | Comparison + use cases |
| Activation | Onboarding messaging |
| Conversion | ROI + proof |
| Expansion | Use-case campaigns |
