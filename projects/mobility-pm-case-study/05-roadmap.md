# 05 — Roadmap

## Phase 1 — Validate
**Goal:** prove recurring-route friction exists.

- interviews
- funnel instrumentation
- fake-door test
- prototype usability test

## Phase 2 — MVP
**Goal:** reduce repeat booking effort.

- saved commute
- home-screen shortcut
- live ETA/fare confirmation
- route editing
- basic analytics

## Phase 3 — Optimize
**Goal:** increase value without adding complexity.

- multiple routines
- context-aware ranking
- clearer exception handling
- personalization experiments

## Phase 4 — Expand
**Goal:** explore adjacent recurring mobility jobs.

Potential directions:
- scheduled commute planning
- multimodal comparison
- commuter subscriptions
- workplace / campus mobility flows

### Prioritization principle

Build only when there is evidence that the next layer solves a validated user problem.
